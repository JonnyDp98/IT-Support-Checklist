Este repositorio contiene una checklist de control de acceso utilizada como guía para seguir procedimientos estandarizados y ayudar a prevenir problemas relacionados con la gestión de accesos.

* Archivos

2. Checklist de control de acceso.

- Gestión de controles de acceso.
- Seguimiento de procedimientos.
- Resolución de problemas.
- Aplicación de mejores prácticas de IT Support.
